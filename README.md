# Sistema de Inventario LPC

## Requisitos
- XAMPP (Apache y MySQL)

## Instalación

1. Clonar repositorio:
git clone https://github.com/Olafokjm/Kevin_Julio_AA3_EV01.git

2. Mover carpeta a:
C:\xampp\htdocs

3. Iniciar XAMPP:
- Apache
- MySQL

4. Crear base de datos:
- Ir a http://localhost/phpmyadmin
- Importar archivo database.sql

5. Ejecutar sistema:
http://localhost/Kevin_Julio_AA1_EV01/index.php
